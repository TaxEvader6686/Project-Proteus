# Project Proteus

Project Proteus is an unofficial submod for **EaWX: Thrawn's Revenge**.

## Development

Ideas and contributions are welcome!
See the [contribution guide](CONTRIBUTING.md) to get started.
Join the [Project Proteus Discord](https://discord.gg/3g6k2v7) to discuss the mod.

Ongoing development takes place on the `Dev` branch.
The `main` branch tracks the public Steam release.

## About this submod

### Features

Read the full description in the [Project Proteus Steam Workshop page](https://steamcommunity.com/sharedfiles/filedetails/?id=3711433343).

- Overhauls all Minor Warlords by providing unique space, ground, and fighter rosters.
- Adds Grunger's Empire, Thorn's Empire, and Imperial Kaikielius, and more!
- Features new heroes, units, and expanded Minor Warlord mission rewards.
- Includes units ported from Fall of the Republic and Revan's Revenge (those mods are not required).

See the [player roster document](https://docs.google.com/document/d/1O1PfMpgP9tFhqAU0pVgCSG-4nkbRrLaLRFT-GzJGPs0) for faction and unit details.

### Play the released submod

1. Subscribe to [Project Proteus on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3711433343).
2. Subscribe to [Thrawn's Revenge](https://steamcommunity.com/sharedfiles/filedetails/?id=1125571106) and wait for Steam to download both mods.
3. In your Steam Library, right-click **Empire at War**, choose `Properties -> General`, and enter the following **Launch Options**:
   ```
   STEAMMOD=3711433343 STEAMMOD=1125571106
   ```
4. Launch **Forces of Corruption**.
